  1. Descarga MEDDESK_Setup.exe desde el botón superior y ábrelo. Download MEDDESK_Setup.exe using the button above and open it.

    ¿Aparece un aviso al descargar?

    El navegador puede decir que el archivo «no se descarga habitualmente» o Windows mostrar «Windows protegió su PC». Es normal en programas nuevos que aún no tienen firma digital de Microsoft: MEDDESK es una herramienta de bajo costo hecha por un intérprete y más adelante tendrá el certificado de firma de Microsoft, con lo que el aviso desaparecerá. El instalador oficial se descarga solo desde este botón.

    • Chrome: «Conservar».
    • Edge: «…» → «Conservar» → «Mostrar más» → «Conservar de todos modos».
    • Windows: «Más información» → «Ejecutar de todas formas».

    Si Microsoft Edge no permite descargarlo, descárguelo con Google Chrome. Microsoft todavía está revisando el instalador (ya lo analizó y no encontró nada malicioso); cuando termine la revisión, Edge también lo permitirá.

    Seeing a warning when downloading?

    Your browser may say the file "isn't commonly downloaded" or Windows may show "Windows protected your PC". This is normal for new programs that don't yet have a Microsoft digital signature: MEDDESK is a low-cost tool made by an interpreter and will later get a Microsoft signing certificate, making the warning disappear. The official installer is downloaded only from this button.

    • Chrome: "Keep".
    • Edge: "…" → "Keep" → "Show more" → "Keep anyway".
    • Windows: "More info" → "Run anyway".

    If Microsoft Edge won't let you download it, download it with Google Chrome. Microsoft is still reviewing the installer (it already scanned it and found nothing malicious); once the review is done, Edge will allow it too.

  2. Si Windows muestra «Windows protegió su PC», pulsa Más información y luego Ejecutar de todas formas. Aparece porque el instalador es nuevo y aún no tiene firma digital. Solo aparece la primera vez, al instalar; abrir MEDDESK y las actualizaciones automáticas no lo muestran. If Windows shows "Windows protected your PC", click More info and then Run anyway. It appears because the installer is new and not yet digitally signed. It only appears the first time, when installing; opening MEDDESK and automatic updates don't show it.
  3. Sigue el asistente de instalación (no requiere cables virtuales ni configuraciones complicadas). Follow the setup wizard (no virtual audio cables or complicated configuration required).
  4. Abre MEDDESK, pulsa Crear cuenta, ingresa tu correo, escribe el código de 6 dígitos y crea tu contraseña. Open MEDDESK, click Create account, enter your email, type the 6-digit code, and choose your password.
